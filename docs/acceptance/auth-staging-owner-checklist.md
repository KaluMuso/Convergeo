Source preparation only. Hosted settings, accounts, mail delivery, payment,
fulfilment, and reconciliation were not exercised by this task. Use the existing
[public handoff](converged-candidate-public-handoff.md),

defines Site URL defaults, allowlist matching, and `RedirectTo` email-template behavior.
