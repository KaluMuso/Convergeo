# Agent board

The shared to-do list for everyone building Convergeo: **King** (founder, approves), **Claude** (architect, reviewer, merge captain, releases), **Cursor** (implementer, using Grok models), **Grok Bot** (chores and routines) and **Grok Build** (implementer, if used).

GitHub is the source of truth. This file says who is doing what; PRs carry the work; Slack `#convergeo-agents` carries the pings.

## Rules

1. **Claim before you start.** Edit your row to `in progress — <agent>` in the same PR or commit as your first change. One agent per row.
2. **One task means one branch and one PR.** Use the branch named in the task, or `cursor/<name>`, `grok/<name>` or `claude/<name>`.
3. **Nobody but King merges to `master`.** Claude merges feature PRs into `release/*` after review. Agents never merge.
4. **Hands off without Claude's review:** `supabase/migrations/`, `scripts/ci/`, `.github/workflows/`, payments (Lenco), auth, RLS, money code. Propose the change in a PR and flag it on the board.
5. **No secrets** in code, prompts, PRs or chat. Agents never get production keys (Supabase service role, Lenco, Vercel, server).
6. **No force-push, no branch deletion, no `git stash` without a unique tag.**
7. **When done:** set your row to `ready for review`, add one line of notes, and post the PR link in Slack.

## Status values

`todo` · `in progress — <agent>` · `ready for review` · `changes requested` · `merged to release` · `live` · `blocked: <why>`
