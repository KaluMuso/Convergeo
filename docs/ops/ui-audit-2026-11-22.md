## Top 5 to fix first

1. **Home product stream missing** — shoppers see categories then seller pitch with no products (393 + 1280).
2. **Checkout with empty cart + bottom nav** — guard cart and remove shop chrome from checkout.
3. **Home cold load >3 s** — hurts first impression on 3G targets.
4. **FAB overlap** (home categories, help articles, saved/cart) — use route-aware FAB offsets.
5. **Stuck “Loading categories…”** — undermines trust in header nav site-wide.
